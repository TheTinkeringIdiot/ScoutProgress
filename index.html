Drop a Pack Recognition Report here or click to choose the CSV file. Nothing is uploaded: the report is read right here in your browser.

How to get the report from Scoutbook

  1. In Scoutbook, open the Pack Recognition Report.
  2. Set Start Date for Completed Awards to June 1 of the current scouting year, and End Date to today.
  3. Tick all four boxes:
    • Include Awarded Within Date Range
    • Include Not-Awarded Regardless of Date Range
    • Include Data for Current Members Only
    • Include advancements earned outside of this unit
  4. Set Sort By to All Sorts. This page reads the “By Den” part of the report, which that option includes.
  5. Click the blue CSV button to download the file, then drop it in the box above.

Scoutbook may still include older items. Anything dated before June 1 is ignored here.
